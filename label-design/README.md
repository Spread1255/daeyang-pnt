# ZebraDesigner 3 라벨 만들기 안내 (130 × 100mm)

관리자 페이지 [라벨 출력]과 같은 라벨을 ZebraDesigner 3에서 직접 만들 때 쓰는 안내입니다.
ZebraDesigner 라벨 파일(.nlbl)은 Zebra 전용 형식이라 프로그램 밖에서 만들 수 없으므로, 아래 위치·크기대로 한 번 만들어 저장해 두고 계속 쓰면 됩니다.

- `label-130x100-reference.png` : 완성 모습 (300dpi, 실제 크기 기준)
- `ghs-png/GHS01.png ~ GHS09.png` : 그림문자 (흑백). ZebraDesigner의 [그래픽]으로 넣습니다.

이 폴더는 홈페이지에 올라가지 않습니다.

---

## 1. 새 라벨 설정

1. ZebraDesigner 3 → **새 라벨** → 프린터 **ZDesigner ZT421** 선택
2. 라벨 크기: **너비 130mm, 높이 100mm**, 방향 **가로**, 여백 0
3. 단위: **mm** (파일 → 옵션 → 측정 단위)
4. 글꼴은 모두 Windows 글꼴(바탕, 맑은 고딕)을 씁니다. 한글은 프린터 내장 글꼴이 없으므로 Windows 글꼴로 두면 자동으로 그림으로 보내집니다.

## 6. 번호 (No. 1 ~ No. 30)

1. 번호 글자 칸의 데이터 원본을 **카운터(Counter)** 변수로 만듭니다.
2. 시작 값 **1**, 증가 **1**, 앞에 붙는 글자(접두사) **`No. `**
3. 인쇄할 때 매수에 30을 넣으면 No. 1부터 No. 30까지 차례로 찍힙니다.
4. 다음에 이어서 뽑을 때는 카운터 시작 값을 바꾸거나 [인쇄할 때 입력]으로 둡니다.

ZebraDesigner 3 무료(Essentials) 판에서 카운터를 쓸 수 없으면, 관리자 페이지 [라벨 출력]의 [인쇄] 또는 [ZPL 파일 저장]을 쓰면 번호가 자동으로 들어갑니다.

## 7. 확인

- 완성 후 `label-130x100-reference.png`와 미리보기를 나란히 놓고 위치를 맞춰 봅니다.
- 첫 출력은 2~3장만 뽑아 번호·QR 코드(휴대폰으로 스캔)·작은 글씨를 확인합니다.
- 프린터가 203dpi면 문구(약 2.9mm)·하단 글씨(2mm)는 굵게 하지 않습니다. 굵게 하면 획이 붙어 뭉개질 수 있습니다.
