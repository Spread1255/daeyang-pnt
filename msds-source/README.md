# MSDS 작성 자료 (백업)

MSDS 작성용 원본·데이터·도구를 보관하는 폴더입니다.
`.vercelignore`로 배포에서 빠지므로 홈페이지에서는 열리지 않습니다.
홈페이지 공개는 관리자 화면에서 등록해야 하며, 공개/비공개 설정을 따릅니다.

## 폴더
| 폴더 | 내용 |
|---|---|
| `output/` | 최근 생성한 MSDS (엑셀·PDF) |
| `old/` | 이전 버전 (번호·범위 규칙 변경 전) — 사용하지 않음 |
| `data/MSDS 원료 사전.xlsx` | 원료명 → CAS·KOSHA 분류·노출기준, 제품 수집 현황 |
| `data/MSDS 함유량 범위 기준.md` | 함유량 범위 규칙과 분석 기록 |
| `data/kosha/<CAS>.txt` | KOSHA MSDS 상세 페이지에서 뽑은 16개 항목 원문 |
| `tools/` | 생성 스크립트(작업용) — 자동화 생성기 제작 시 정리 예정 |

## 작성 규칙 요약
- 원료는 작업지시서 NO 순서 (DFA 제외), 0.01% 미만 제외
- 함유량 범위: `data/MSDS 함유량 범위 기준.md` (수지는 정수 ±2)
- 2번 유해성: 급성 독성(경구) 4 · 피부 자극성 2 · 발암성 2 (H351·H315·H302, GHS07·GHS08)
  - 이산화티타늄이 없으면 발암성·H351·GHS08 제외, YELLOW P210 함유 제품은 발암성 1A(H350·위험)
- 생성: `tools/batch1.py`(140~173), `batch2.py`(POWDER·보류분), `batch3.py`(함마톤) → `verify*.js` 검사 → `render_batch*.js` PDF
- 최초작성일 2024-05-09, 개정횟수 1 회, 최종개정일자 2026-01-06
- 파일명: `코드 제품명(내장형/외장형 제외) MSDS`

작업지시서 원본(.xls)은 원료단가표(거래처·단가)가 들어 있어 여기에 넣지 않았습니다.
